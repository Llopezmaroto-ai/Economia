Importar / Exportar datos

Uso de almacenamiento local seguro

ℹ️ Los datos se guardan en IndexedDB, una base de datos local del navegador más robusta que localStorage. Mantén copias de seguridad periódicas en JSON.

💾 Exportar

Descarga todos tus datos (JSON) o los movimientos (CSV).

📂 Importar copia de seguridad

Restaura desde un JSON exportado anteriormente. Reemplazará todos los datos actuales.

📋 Importar movimientos desde CSV

El CSV debe tener las columnas: fecha, mesReferencia, concepto, importe, tipo, categoria, subcategoria, metodo, comentario. Si no incluye mesReferencia, se usará el mes de la fecha real.

Los tipos válidos son: ingreso | gasto | ahorro | aportacion

Regla contable rápida

Gasto = dinero que sale de tu patrimonio. Aportación = dinero que pasa de efectivo a inversión. Traspaso interno = dinero que cambia de un producto a otro. Rentabilidad = cambio de valor del producto, no movimiento de dinero.
